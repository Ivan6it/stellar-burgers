# Stellar Burgers

Веб-приложение для заказа бургеров, разработанное в рамках проектной работы 11-го спринта.

Проект представляет собой React-приложение с взаимодействием с сервером, авторизацией пользователей, защищёнными маршрутами и глобальным управлением состоянием.

## О проекте

В рамках командной проектной работы участники распределяли между собой отдельные задачи и зоны ответственности.

Моя часть работы была связана с:

- настройкой клиентской маршрутизации;
- реализацией запросов к серверу;
- работой с Redux и глобальным "store";
- настройкой авторизации;
- созданием защищённых маршрутов.

### Технологии

- React — разработка пользовательского интерфейса
- TypeScript — типизация приложения
- Redux — управление глобальным состоянием
- React Router — клиентская маршрутизация
- REST API — взаимодействие с сервером

### Авторизация

В проекте реализована авторизация пользователей и разграничение доступа к маршрутам.

Для страниц, доступных только авторизованным пользователям, используются защищённые маршруты.

### Работа с API

Для получения и отправки данных используется API проекта.

Запросы к серверу интегрированы с глобальным состоянием приложения через Redux.

URL API передаётся через переменную окружения:

BURGER_API_URL=<API_URL>

Пример переменной находится в ".env.example".

## Запуск проекта

Клонировать репозиторий:

git clone https://github.com/Ivan6it/stellar-burgers.git

Перейти в директорию проекта:

cd stellar-burgers

Установить зависимости:

npm install

Запустить проект:

npm run start
